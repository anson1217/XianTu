# 選檔年齡顯示修補

2026-11-19：角色管理的單機與雲端存檔卡片原本直接讀取 `角色.属性.寿命.当前`。該欄位可能停留在開局的 12 歲；遊戲內人物頁則早已使用出生日期計算，所以顯示不一致。

改由 `getPlayerAgeForDisplay` 使用每個存檔自己的 `角色.身份.出生日期` 與 `元数据.时间`，共用既有周歲計算。舊存檔缺漏或日期無效時，回退到有效的原年齡；兩者皆無有效值時維持原本 18 歲的預設。顯示計算不寫入存檔、不改出生日期或壽元上限，亦不修改 NPC、AI 時間指令與遊戲機制。

驗收：

```powershell
node scripts/test-save-age.mjs
npm run type-check
npm run lint:check
npm run build
```

測試使用合成資料，涵蓋生日當天／前一天／後一天、跨多年、序列化重載、兩個不同日期的存檔各自顯示、缺漏與無效日期、零歲及唯讀不變性。另抽取實際兩處卡片年齡綁定交由 Vue 渲染，確認單機舊槽顯示 12 歲、雲端較新槽顯示 17 歲，即使其舊 `寿命.当前` 都仍為 12。NPC 原有跨生日自動增齡亦保持。

Pages 既有部署流程加入此回歸檢查。未讀取、修改或提交玩家的正式存檔。
